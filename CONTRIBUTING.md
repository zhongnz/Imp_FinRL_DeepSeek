# Contributing to Imp_FinRL_DeepSeek

Thank you for your interest in contributing to this implementation of FinRL_DeepSeek!

## About This Repository

This repository is a replication/implementation of the [FinRL_DeepSeek](https://github.com/benstaf/FinRL_DeepSeek) project. The goal is to make the research accessible and reproducible.

## How to Contribute

### Reporting Issues

If you find bugs or have suggestions:

1. Check if the issue exists in the [original repository](https://github.com/benstaf/FinRL_DeepSeek)
2. Search existing issues to avoid duplicates
3. Provide detailed information:
   - Environment details (OS, Python version, etc.)
   - Steps to reproduce
   - Expected vs actual behavior
   - Error messages and logs

### Suggesting Enhancements

We welcome suggestions for:
- Documentation improvements
- Code optimizations
- Additional LLM integrations
- New evaluation metrics
- Better data preprocessing

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Test thoroughly
5. Commit with clear messages
6. Push to your fork
7. Submit a pull request

## Development Guidelines

### Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions focused and modular

### Testing

Before submitting:
- Ensure Python files are syntactically correct
- Test that imports work
- Verify training scripts can initialize (even if not running full training)
- Check that data processing scripts handle edge cases

### Documentation

When adding features:
- Update README.md if needed
- Add usage examples
- Document any new dependencies
- Update SETUP.md for installation changes

## Areas That Need Help

We especially welcome contributions in:

1. **Documentation**
   - More detailed tutorials

2. **Testing**
   - Unit tests for environments

3. **Features**
   - Support for additional LLM providers

4. **Data Processing**
   - Alternative data sources
   - More efficient preprocessing
